# Ghorowa (ঘরোয়া) — ই-কমার্স ওয়েবসাইট

বাচ্চাদের পোশাক দিয়ে শুরু, পরে পুরো পরিবারের সবকিছু। Next.js + Supabase (PostgreSQL), পুরোটা বাংলায়।

## কী কী আছে

**দোকান (ক্রেতাদের জন্য)**
- হোম পেজ: অটো-স্লাইডার কভার, ক্যাটাগরি আইকন, কাউন্টডাউনসহ ফ্ল্যাশ সেল, নতুন এসেছে, বেস্ট সেলার, মেয়ে/ছেলে/বেবি সেকশন
- কুইক অ্যাড (কার্ড থেকেই সাইজ বেছে কার্টে), পাশ থেকে খোলা কার্ট ড্রয়ার
- মোবাইলে নিচে স্থায়ী মেনু, ভাসমান WhatsApp বাটন, স্টিকি হেডার
- ক্যাটাগরি পেজে মেয়ে/ছেলে/বয়স ফিল্টার ও দাম অনুযায়ী সাজানো
- প্রোডাক্ট পেজ: ছবির গ্যালারি, সাইজ/রং, এখনই কিনুন, WhatsApp-এ অর্ডার
- চেকআউট: ক্যাশ অন ডেলিভারি, বিকাশ সেন্ড মানি, বিকাশ অনলাইন পেমেন্ট
- কাস্টমার অ্যাকাউন্ট (মোবাইল নম্বর + পাসওয়ার্ড): অর্ডারের ইতিহাস, ডেলিভারির অবস্থা, সেভ করা ঠিকানা
- অর্ডার ট্র্যাক (`/track`) — অ্যাকাউন্ট ছাড়াও অর্ডার নম্বর + ফোন দিয়ে

**অ্যাডমিন প্যানেল (`/admin`)**
- লগইন: প্রথমবার Vercel-এর `ADMIN_EMAIL` / `ADMIN_PASSWORD` দিয়ে। এরপর **সেটিংস** থেকে নিজের পাসওয়ার্ড বদলানো যায়,
  আর লগইন পেজে **"পাসওয়ার্ড ভুলে গেছেন?"** থেকে ইমেইল/টেলিগ্রামে রিসেট লিংক আসে। Vercel-এর `ADMIN_PASSWORD` মাস্টার পাসওয়ার্ড হিসেবে সবসময় কাজ করে।
- ড্যাশবোর্ড: নতুন অর্ডার, আজকের বিক্রি
- অর্ডার: তালিকা, খোঁজা, স্ট্যাটাস বদলানো, Steadfast-এ এক ক্লিকে পার্সেল বুকিং ও ট্র্যাকিং
- পণ্য: যোগ/এডিট/মুছে ফেলা, একসাথে অনেক ছবি আপলোড (ব্রাউজারেই ছোট হয়ে যায়), স্টক ও দেখানো/লুকানো
- ক্যাটাগরি: নতুন ক্যাটাগরি, চালু/বন্ধ ("শীঘ্রই আসছে")

## লাইভ করার ধাপ

### ১. Supabase (ডাটাবেস ও ছবি)
1. https://supabase.com এ অ্যাকাউন্ট খুলে **New project** বানান (Region: Singapore বা Mumbai)।
2. বাঁ পাশে **SQL Editor → New query**-তে [`supabase/setup.sql`](supabase/setup.sql) ফাইলের পুরোটা পেস্ট করে **Run** চাপুন। টেবিল, নমুনা পণ্য আর ছবির স্টোরেজ তৈরি হয়ে যাবে।
3. **Project Settings → Database → Connection string → Transaction pooler** থেকে URL কপি করুন (পাসওয়ার্ড বসিয়ে) — এটা `DATABASE_URL`।
4. **Project Settings → Data API** থেকে Project URL (`SUPABASE_URL`), আর **Project Settings → API Keys → Secret keys** থেকে `sb_secret_…` কী (`SUPABASE_SERVICE_ROLE_KEY`) কপি করুন।

### ২. Vercel
1. https://vercel.com → **Add New → Project** → `ghorowa` repo।
2. **Environment Variables**-এ [`.env.example`](.env.example)-এর "অবশ্যই লাগবে" অংশের সবগুলো দিন।
3. **Deploy**। এরপর `https://আপনার-সাইট/admin`-এ গিয়ে `ADMIN_EMAIL`/`ADMIN_PASSWORD` দিয়ে লগইন করুন।

> বিল্ডের সময় ডাটাবেস থেকে পণ্য পড়ে পেজ তৈরি হয়, তাই `DATABASE_URL` ছাড়া Vercel-এ বিল্ড হবে না।

## ডেভেলপারদের জন্য

```bash
cp .env.example .env.local     # DATABASE_URL, AUTH_SECRET, ADMIN_* দিন
npm install
npm run db:setup               # টেবিল তৈরি + নমুনা ডেটা (লোকাল/যেকোনো Postgres)
npm run dev
```

- স্কিমা: `src/db/schema.ts`। বদলালে `npm run db:generate` (নতুন মাইগ্রেশন) ও `npm run db:supabase-sql` (setup.sql আপডেট)।
  Supabase-এ আগে setup.sql চালানো থাকলে নতুন মাইগ্রেশনের SQL ফাইলটা SQL Editor-এ আলাদা করে চালান।
- পণ্যের তালিকা `use cache` দিয়ে ক্যাশ হয়; অ্যাডমিনে বদলালে `updateTag("catalog")` দিয়ে সাথে সাথে আপডেট হয়।
- অর্ডারের দাম সবসময় সার্ভারে ডাটাবেস থেকে হিসাব হয়। সব টেবিলে RLS চালু, তাই Supabase-এর পাবলিক API দিয়ে ডেটা পড়া যায় না।
- লোকাল ডেভেলপমেন্টে Supabase না দিলে ছবি `public/uploads`-এ জমা হয়।
